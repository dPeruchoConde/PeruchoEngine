# PeruchoEngine

Tis is a personal videogame engine and editor project that I'm working on to improve my c++ skills. Right now it uses raylib for the rendering but I'm planning to replace it with my own rendering pipeline in the future.
The project is divided in three parts:
- PeruchoEngine: The game engine with the ECS render and updates, the components code and the scene manager. It's compilled into a dll.
- PeruchoEditor: The editor of the engine.
- PGame: The games dll with all the entities code.
